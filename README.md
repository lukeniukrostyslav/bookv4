# BOOKV4 — Commercial eBook Project

This repository is the new commercial-book project.

## Core principle

Market first → reader first → concept → architecture → manuscript → editorial QA → production → distribution.

BOOKV3 is used as a process reference. Its manuscript, characters, world, and other book-specific creative content are **not copied** into BOOKV4.

## Operating rules

- Every material decision is documented.
- Progress percentages are evidence-based.
- No block reaches 100% without a verifiable completion criterion.
- Market claims require dated sources.
- Do not promise bestseller status; optimize the process for commercial fit.
- Preserve checkpoints and recovery information in GitHub.
- Owner actions are clearly separated from autonomous work.
